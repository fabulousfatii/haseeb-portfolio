# Muhammad Haseeb — Portfolio

Personal portfolio inspired by [tajmirul.site](https://www.tajmirul.site/).

## Run locally

Open `index.html` in a browser, or from this folder:

```bash
npx serve .
```

## Customizing

- Replace GitHub / LinkedIn URLs in `index.html`.
- Drop screenshots into the project cards later (the gray `Add image` blocks are placeholders).
- Content is based on `MuhammadHaseeb.pdf`.
